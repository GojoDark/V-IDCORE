TRANSPARÊNCIA

Como calculamos

cm/360 mede a distância física necessária para girar 360°. É a base mais segura para hipfire entre jogos.

cm/360 = 914.4 / (DPI × sens × yaw)

CS2 usa yaw 0.022. VALORANT usa 0.07 na conversão hipfire adotada pelo Hub. R6 usa o multiplier configurável do GameSettings.ini para hipfire.
